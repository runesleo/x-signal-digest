每个文件里有五块，对应模板表单：名字、一句话、系统指令、默认定时、首次使用引导。系统指令整段复制，不要改条数和「今天没有」这句。

Bot 只做认知层：每天 0–3 条，附原帖链接和为什么值得知道。开源内核里的 0/1 正式写回和本地回执留在自建版，不放进这条指令。

筛选顺序按仓库公开案例的结论来写：一手来源，以及会不会改变这个人今天的做法或判断，排在互动量前面。Python 预排序（新鲜度、互动、字段是否齐全）不写进 Bot 指令。
