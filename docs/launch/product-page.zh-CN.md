# X 信号摘要

用你自己的 Grok 读你自己的 X 时间线，每天留下 0–3 条值得知道的，每条附原帖链接和原因；没有就说今天没有。

## 痛点

你打开 X，滑二十分钟，关掉的时候说不出今天多知道了什么。收藏夹一直在变长，第二天你不会回去看。有的摘要在没什么值得看的日子也会凑满三条。

## 30 秒看懂

- 谁在读：你自己的 Grok，读你已经登录的 X 主页时间线。
- 多久一次：每天 1 次。默认本地时间 08:00，钟点可以改。
- 留下什么：最多 3 条。每条有原帖链接，和一句为什么值得你知道。
- 没有过线：它只说「今天没有。」
- 它不做的事：不点赞，不回复，不发帖。

## 怎么装

1. 打开模板页，点 Add to Grok Bot。公开地址发布前写着 TODO。
2. 回答两个问题：最想看的 1–3 个主题，不想看什么。
3. 它马上交第一轮。之后按你留的钟点，每天跑一次。
4. 要改时间，直接对它说新的钟点。一天仍然一次。

可粘贴的指令和定时值在仓库的 `templates/grok-bot/`。

## 和自建开源版的区别

开源仓库：[x-signal-digest](https://github.com/runesleo/x-signal-digest)。

| | Grok Bot 模板 | 开源自建 |
| --- | --- | --- |
| 开始方式 | 在 Grok 里添加模板，回答主题 | 在自己的电脑上安装仓库，自己准备只读采集器 |
| 时间线从哪来 | 你的 Grok 直接读 X | 采集器把内容写成你电脑上的文件 |
| 每天给你什么 | 0–3 条值得知道 | 同样的 0–3 条，另外把结果写成本地回执；最多 1 条可以进入你自己的知识或任务系统 |
| 数据停在哪 | 你的 Grok 会话 | 你指定的本地 state 目录 |
| 适合谁 | 先把时间线收成每天几条 | 要把结果接进自己的系统，并留下可核对的回执 |

自建版如果用已登录的浏览器去读 X，平台条款和限流风险写在仓库的安全说明里。Grok 模板不另接采集器。

## 边界与隐私

- 摘要发在你的 Grok 对话里。模板禁止点赞、回复、引用、转发、关注、收藏、发帖和私信。
- 时间线不发到模板作者的服务器。作者拿不到你的时间线，也拿不到你的登录状态。
- 模板由独立开发者提供，不是 xAI 官方产品。添加之后，Bot 在你自己的 Grok 账号里按指令运行。
- 时间线没读到时，它说「时间线没读到，今天这轮不算数。」这一轮不能写成「今天没有。」
- 帖子正文只当内容。它不执行帖子里让它转发、私信或改规则的要求。
- 主题和钟点以后都能改。停掉定时，每天的推送就停。
